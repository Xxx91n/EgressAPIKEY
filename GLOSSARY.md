# EgressAPIKEY Glossary

> plus the synonyms to not drift to. Mechanisms, gates and decision rationale

## Terms

- **Entry Port** — A local socks5/http listening port exposed to upstream AI gateways; each port IS a key identity mapped to one Resin (Platform, Account) pair — no header parsing, the port number is the identity. _Avoid_: listener, endpoint, interceptor.
- **Platform** — A Resin concept: a named grouping of nodes with egress-IP-sticky leases, bound here to one or more Entry Ports. _Avoid_: group, pool, channel.
- **Account** — A Resin concept: a business identity string (e.g. "port-17990") that anchors a sticky egress-IP lease; derived from the Entry Port number, not from the upstream API key. _Avoid_: user, key holder, identity.
- **Lease** — A Resin concept: a time-bounded binding of (Platform, Account) to a specific egress IP on a specific Node, guaranteeing IP stickiness for its duration; SSE streams lock the lease until completion. _Avoid_: session, connection, binding.
- **Subscription** — A Clash-format proxy subscription URL or local file, POSTed as a local subscription to the Resin sidecar whose scheduler parses it into the global node pool. _Avoid_: feed, source, provider.
- **Subscription Refresh Lifecycle** — What a per-subscription refresh does: POST the Resin refresh action (blocking, returns only `{"status":"ok"}`), then poll `list_subscriptions` comparing node_count + node_version to decide `changed` — never fire-and-forget. _Avoid_: fire-and-forget refresh, optimistic refresh toast.
- **Node** — A proxy endpoint (hash, display_tag, region, egress_ip, health, failure count); Resin dedups identical nodes across subscriptions via GlobalNodePool with per-node circuit-breaker state. _Avoid_: server, proxy, relay.
- **Ghost Safety Net** — The shell's health monitor for the sidecar: 3s /healthz poll; after 3 consecutive failures it flips the tray red, clears the OS system proxy, emits `sidecar-status: unhealthy`, and performs a bounded real restart (see Crash Restart). _Avoid_: watchdog, monitor, guardian.
- **Sidecar** — The Resin Go binary spawned as a child process of the shell; owns the scheduler, latency tracking, lease table and node runtime, reachable only via loopback REST (admin token never crosses to the webview). _Avoid_: kernel, engine, daemon.
- **Egress IP Policy** — Resin's native `allocation_policy` enum (BALANCED / PREFER_LOW_LATENCY / PREFER_IDLE_IP) — the only real exit-selection knobs. _Avoid_: exit strategy, routing mode, selection algorithm.
- **Topology Canvas** — The three-column ReactFlow canvas: Entry Ports (left), Platforms (center), Node Groups by region (right); dragging a platform→region edge live-PATCHes Resin region_filters. _Avoid_: graph, diagram, map.
- **Strategy Layer** — The shell's pluggable decision layer that biases platform configuration and node selection (liveness, latency, quality, protocol weight, IP reputation); per-platform opt-in. _Avoid_: optimizer, scheduler, balancer.
- **AI Stream Sensor** — The module that detects AI traffic shapes (SSE, WebSocket, chunked) and applies per-stream policies (lease locking during SSE, mid-stream failover prevention). _Avoid_: traffic analyzer, stream handler.
- **IP Reputation Provider** — A pluggable external API scoring egress-IP trust (IPQualityScore, AbuseIPDB, ip-api.com); the shell deliberately does NOT use Resin's region-only GeoIP endpoints — the decision input is reputation, not geography. _Avoid_: IP checker, fraud detector, Resin GeoIP as the reputation source.
- **Mixed Protocol** — The default entry-port protocol: one listener accepts both HTTP-proxy and SOCKS5 clients, disambiguated by the connection's first byte (0x05 = SOCKS5, else HTTP); explicit http/socks5 values stay single-protocol. _Avoid_: auto-detect port, dual listener.
- **Protocol Weight** — A documented (not runtime-injected) suitability ranking of outbound node protocols for SSE/WS streams, used by the Strategy Layer to bias selection. _Avoid_: protocol score, transport rating.
- **Backup** — A zip of the Backup Scope ledger with a per-member SHA-256 `manifest.json`, optionally sealed with a passphrase envelope (ChaCha20-Poly1305 + PBKDF2-HMAC-SHA256 KEK); restore re-enters the same write entries, L3/audit unpacked read-only as evidence. _Avoid_: snapshot, checkpoint, save.
- **Backup Scope** — The three-class ledger of what a backup may contain: config-layer (whitebox files + backup/ ring + audit JSONL, restorable), L3-derived (`state.db`/`cache.db` read-only snapshots, never written back), and `request_logs*.db` (never, any class). _Avoid_: backup layer, backup tier, backup kind.
- **Data-Plane Mode** — Which process listens on an Entry Port and how the client authenticates: Mode A = shell forwarder injects the port's credential (desktop default, credential-free client); Mode B = Resin listens natively, client presents `Platform.Account` once (headless/VPS default). _Avoid_: zero-adapt (only Mode A is credential-free), dual proxy.
- **Entry Port Mapping** — The SQLite table pairing each Entry Port with its (platform_name, protocol, label, account_string) metadata; the port being live IS the account identity (no header injection). _Avoid_: port table, route map, binding table.
- **hotswap-config** — The whitebox configuration layer: user-editable files re-read and applied without restarting the sidecar, with atomic backup before apply. _Avoid_: live config, dynamic config, reload.
- **Request Log** — The daily-rotating tracing file appender (10MB × 7) capturing Rust-side logs; openable from Settings > Storage. _Avoid_: audit trail, access log, debug log.
- **Headless Control Plane** — The browser SPA + Rust headless BFF reproducing the desktop control surface without Tauri; the BFF holds the admin token server-side, refuses non-loopback binds without an explicit auth token, and rejects unexpected Host/Origin. _Avoid_: admin web panel, public dashboard.
- **RunningMode** — The enum (Sidecar | NotRunning) saying whether the Resin binary is alive as a child of the shell, held in an ArcSwap for lock-free reads; distinct from the Ghost health state. _Avoid_: process state, alive flag.
- **Ring Buffer** — The bounded (500-entry) VecDeque draining sidecar stderr, exposed as the `get_sidecar_logs` IPC snapshot plus a `sidecar-stderr` event push. _Avoid_: log buffer, pipe drain, stderr cache.
- **Crash Restart** — The bounded auto-retry inside the Ghost Safety Net: up to 3 real restarts (1s/2s/4s backoff, same control-plane port and admin token), then the sidecar is marked Terminated and the user must restart the app. _Avoid_: watchdog respawn, auto-recover.
- **Two-Phase Shutdown** — The kill sequence: SIGTERM the process group → wait → SIGKILL if still alive → reap; process-group kill prevents orphan children holding the port. _Avoid_: graceful kill, soft terminate.
- **Port Cleanup** — Before spawning a sidecar, SIGTERM any stale process holding the configured free port. _Avoid_: port preflight, stale-process sweep.
- **Upstream Manifest** — `docs/RESIN_UPSTREAM_MANIFEST.yaml`: the pinned sidecar version, hashes, release URL and compat notes; bumps are manual edit + test + commit, never auto-followed. _Avoid_: version pin, compat matrix, version tracker.
- **Write Retry** — The bounded transient-failure retry on ResinClient write verbs (2 retries on 5xx/network errors; 4xx never) living in ResinClient so every write IPC benefits; safe because creates are name-keyed. _Avoid_: write retry loop, idempotent retry, backoff.
- **Subscription Update Interval** — How often Resin re-pulls a remote subscription; upstream enforces a ≥30s floor on create and update, so the shell default is 30s and smaller values are rejected 400. _Avoid_: poll interval, fetch interval, refresh interval.
- **Subscription Lifecycle** — import (row on Resin) → bind (named in a platform's whitebox `subscriptions`) → activate (`strategy_apply` derives region_filters) → observe (snapshot reverse-lookup); importing is NOT binding, binding is NOT activating. _Avoid_: import = effective, silent cascade, auto-bind-everything.
- **Imported-but-unbound** — A subscription on Resin with node_count > 0 that no whitebox platform names; surfaced as an amber badge with a one-click bind step — zero consumers is not an error but must never be silent. _Avoid_: orphan subscription, dead import.
- **Cascade Phase** — The establish cascade for `subscription_add pipeline=establish`: create_subscription → resolve → establish platform → strategy_config_put → strategy_apply; level-triggered, idempotent per step, a failed step is persistent state (backoff, then parked). _Avoid_: callback cascade, auto-establish.
- **SubscriptionPhase** — The per-subscription establish STATUS record in the strategy whitebox top-level `subscriptions` array: Never / Importing / Establishing / Converged / Failed / NeedsApproval; status writes never bump the generation counter (k8s status-subresource rule). _Avoid_: subscription status vs `PlatformStrategy::subscriptions` name refs, phase as desired state.
- **Cascade Error Rollback** — The explicit per-failed-pass compensation: only resources THIS pass created are undone (the Resin platform row when applicable), never the subscription or the whitebox; outcome persists as `last_cascade_error` on the status row. _Avoid_: auto-heal, whitebox rollback, generic rollback.
- **Generation** — The whitebox write-authority counter (k8s `metadata.generation`): every sanctioned write of `egressapikey-strategy.json` bumps it inside the write entry; the ports file carries its own single counter; 0 = NeverApplied, not "pending". _Avoid_: revision (UI says rev N), version (that is the schema byte), epoch.
- **AppliedGeneration** — The observed half of the pair: the generation the last FULLY GREEN `strategy_apply` landed at, written back in the same store entry; a failed pass keeps the old value and records `last_apply_error`. _Avoid_: last applied revision, apply attempt counter.
- **ConvergePhase** — The top-level six-state convergence derivation: NeverApplied / Unknown (Resin down) / ApplyFailed / PendingApply / Drifted / Converged, rendered as the Effective Config header chip; pure derivation over the snapshot, zero extra requests. _Avoid_: sync status (that's the per-entry three-state), health, auto-reconcile trigger.
- **A-Class Strategy** — Which IP nodes enter a Platform: manual / region / quality / subscription modes (manual + one auto may coexist) behind a mandatory liveness gate; lands on Resin as region-filter sets, not per-node pinning. _Avoid_: ingress filter, node selector, admission policy.
- **B-Class Strategy** — How a platform allocates an exit IP: exactly one of the three Resin-native allocation policies; the six legacy shell tokens survive only as accepted input spellings rewritten once at boot. _Avoid_: fake strategy, display-only parameter, six-strategy catalog.
- **Strategy Engine** — The shell-side module (`strategy_engine.rs`) owning A/B-class evaluation: polls node health/latency, computes region_filters PATCHes, biases lease selection. _Avoid_: optimizer, scheduler, balancer.
- **Strategy Pipeline Vocabularies** — The three deliberately-unmerged vocabularies: catalog (`strategy.rs` StrategyId), planner (`strategy_engine.rs` StrategyConfig/compute_plan), display mapping (`src/lib/strategy.ts`); `StrategyService` is the only owner of the strategyConfig lifecycle. _Avoid_: strategy monolith, vocabulary merge, three-source config.
- **Port Auth Info** — The SOCKS5 credentials for an Entry Port: username = `Platform.Account`, password = the proxy token; per-port no-auth is unsupported (token is global). _Avoid_: socks credentials, proxy auth, port password.
- **Port Health Check** — The IPC probe that TCP-connects to an Entry Port (optionally a SOCKS5 handshake) returning { reachable, auth_required, latency_ms }. _Avoid_: port probe, listener test, connectivity check.
- **Drift Notification** — The tray notification fired per drift EPISODE: the edge predicate fires only on the false→true rising edge of unacknowledged drift; sustained drift is silent, sidecar-down never notifies. _Avoid_: one-shot notify, armed/re-arm, once per process.
- **Subscription Intent** — The declaration "this platform routes through this subscription": the binding records the subscription itself as the strategy; the covered region set is a derived projection computed at apply time. _Avoid_: region bundle, subscription expansion, subscription group drag-fill.
- **Strategy-Labeled Edge** — A canvas B→C edge annotated with the A-class condition that made it ("manual:N", "region:US", "subscription:subA"); unconditional edges carry no label, auto-strategy edges are non-deletable. _Avoid_: routing line, connection tag, "all allowed" label.
- **Trace ID** — A UUID v4 the frontend injects as `__trace_id` into every IPC call, opened as a tracing span so one grep traces frontend → command → ResinClient → Resin HTTP. _Avoid_: request id, correlation id, span id.
- **IpcError** — The typed error enum every `#[tauri::command]` returns instead of a bare String (BindConflict / InvalidStrategy / ResinUpstream / Internal), each carrying an i18n_key for locale-correct rendering. _Avoid_: IPC exception, command error, tauri error.
- **Account Strategy Tag** — The legacy B-class encoding into the Resin account string (`port_label::tag`); superseded by the native allocation_policy line. _Avoid_: strategy hint, account suffix, egress mode tag.
- **Echo Command** — An IPC command that keeps full input validation but returns a constant success without touching Resin (semantics live upstream); `account_add` / `account_bind_ip` are the two survivors, deleted only when the corresponding Resin endpoint disappears or changes shape. _Avoid_: no-op, stub, dead command.
- **White-box Config** — The user-editable configuration honored as truth (strategy + entry ports + process routes as JSON in the app config dir), re-read on external edits without a restart; distinct from GUI preferences and from derived Resin runtime state. _Avoid_: raw config, hand-edit zone, config dump.
- **Process Route** — One rule binding an OS process name to an entry port, living in the ports whitebox; a route is as live as its target port — the shell does not claim per-process traffic enforcement. _Avoid_: lane route, app firewall rule.
- **L2-First Write Order** — The legislated mutation order: persist intent to the L2 whitebox first, then mutate the L3 runtime; a second-step failure leaves visible drift, never a silent L3-only change or lost intent. _Avoid_: rollback-first, transactional write.
- **Authoritative Write Entry** — The rule that each config layer has exactly ONE writer module every edit flows through (GUI, external file, IPC converge on it); a write that bypasses the entry is a bug. _Avoid_: golden config, master copy, single-writer lock.
- **Authoritative Snapshot** — The read-back answer to "is my config actually in effect": one call reads all layers, merges at the one sanctioned point, and reports consistent / divergent (both values, no silent winner) / missingOnResin per item; views consume, never re-merge. _Avoid_: status poll, health check, merged view.
- **Desired / Live (期望态 / 实况)** — The two columns of the Effective Config view: whitebox intent (L2) vs what the Resin runtime actually has (L3); divergence is surfaced, reconciliation stays an explicit one-way action. _Avoid_: sync, merged view, current config.
- **Known Exemption (已知豁免)** — A user-acknowledged drift entry (id in the whitebox `acknowledged` array): grey "known" badge + silenced notification, NEVER altering the three-state merge; revoked only explicitly. _Avoid_: ignored, muted, auto-healed drift.
- **Reconcile (单向)** — The explicit convergence action (`reconcile_now` / the sync button): strategy apply then ports restore, fail-fast, previewed first, whitebox ALWAYS wins — no accept-current-state, no self-heal, no background loop. _Avoid_: self-heal, auto-sync, accept current state.
- **Deletion Authority (删除权威)** — L2 desired-state entries leave only through an explicit deletion act, never as a side effect of reading live state; "missing on Resin" is drift to re-assert, not a deletion signal, and a live-list-fed write-back hard-rejects an empty list. _Avoid_: auto-prune on save, trusting an empty live list.
- **Whitebox Versioning (白盒版本化)** — Every atomic whitebox write first copies the file to the sibling `backup/` ring (newest 10 kept); rollback re-enters the SAME validate→apply chain, never a bypass. _Avoid_: undo stack, autosave, config trash bin.
- **Audit Event** — One append-only `audit.jsonl` row per L2 mutation (schema/ts/audit_id/target/op/actor/before_hash/after_hash/outcome, chained via prev_hash); best-effort — a failed append degrades to a warning, never blocks the write. _Avoid_: change log, event sourcing, security audit trail.
- **G4 (Signal Channel)** — How the shell learns sidecar state: there is NO Resin webhook (the Admin API is pure pull) — the real channel is the IPC retarget plus the shell's own `sidecar-status` event from the Ghost poll. _Avoid_: Resin webhook, push notification, callback channel.
- **Global Converge Loop** — The app-wide feedback circuit: one `subscribeToConverge()` subscription owns the snapshot cadence (5s foreground, 30s when settled Converged, immediate on `sidecar-status`, paused while hidden); display truth only, writes nothing. _Avoid_: per-view polling ownership, webhook trigger, write path.
- **Account Header Rule** — A Resin control-plane rule mapping a URL prefix to header NAMES to extract the account identity from (L3 state, four thin IPC pass-throughs); coexists with, and is not, process routes. _Avoid_: X-Resin-Account value routing, header-rule-to-port mapping.
- **Name-to-UUID Resolution** — How a name becomes the Resin UUID single-resource endpoints need: centralized helpers (`resolve_platform_id_by_name` etc.) do the list→match→id hop once, with boundary name validation and typed NotFound. _Avoid_: hand-rolled two-step hops, stringly not-found errors.
- **Platform Action** — The three upstream POST action endpoints (reset-to-default, rebuild-routable-view, preview-filter), all deliberate non-adoptions: they would mutate L3 behind the L2 whitebox or duplicate the shell-side snapshot; preview-filter is the only recorded re-wiring candidate. _Avoid_: wiring them through the shell, treating them as unexamined blanks.
- **Request Log Detail** — The single-row view over one Resin request-log entry (`request_log_detail` + base64 `request_log_payloads`, 1 MB per-part cap). _Avoid_: reading `request_logs*.db` directly, rendering multi-MB bodies unsliced.
- **License Layering** — The repo license model: one root GPL-3.0-or-later `LICENSE` with per-layer effective values (shell GPL-3.0-or-later, Resin source MIT, compiled sidecar binary GPL-3.0-or-later by dependency-tree truth); declared vs tree values are both recorded in `THIRD_PARTY.md`. _Avoid_: bare "MIT" for the sidecar, editing the LICENSE text, one flat value.
- **Mere Aggregation** — The legal boundary keeping shell and sidecar independent works: they interact exclusively over the loopback REST seam — no FFI, no embedding, no shared struct surface; breaking the seam voids the analysis. _Avoid_: FFI into resin, embedding the Go tree, calling the seam "linking".
- **Third-Party Provenance** — The evidence discipline: every bundled component registered in `THIRD_PARTY.md` with version/form/declared/tree/upstream, claims cited from upstream originals at the exact tag, re-verified on every version bump. _Avoid_: claims without a source link, relying on a declared license alone.
- **Strategy Template** — A preset of strategy choices applied to a platform THROUGH the single write entry, exactly like a hand edit — never a second config layer, never a bypass of generation/audit. _Avoid_: presets stored outside the whitebox, applying without a generation bump.
- **Strategy Orchestration** — The platform-level conditional-automation state machine reacting to exit-IP risk signals (probe candidates → switch → observe → commit/rollback, with cooldown against flapping); reversible switching may run full-auto on unattended headless, large/destructive actions are never in its repertoire, every transition audit-logged. _Avoid_: per-request routing, content-aware switching (Fork Line territory), silent lease restarts.
- **Fork Line** — The separate product line for data-plane innovations the vendored Resin cannot express, pinned to exactly one trigger: per-request model-field-driven exit switching inside one account (node-level pinning included); until it fires, no fork work and the shell never re-enters the kernel. _Avoid_: patching Resin casually, shell-side kernel forks.
- **Deployment Profile (部署剖面)** — A named runtime context the product must satisfy: low-end VPS headless (1C1G-class) and ordinary Windows desktop; acceptance numbers are legislated per profile. _Avoid_: benchmarking CI runners as target hardware, one profile silently covering both.
- **Acceptance Line (验收线)** — The dual-threshold (target / danger) performance bar per deployment profile that arbitrates ticket priority; gates added-latency deltas and good-event ratios, deliberately narrow in domain. _Avoid_: vanity metrics, throughput gates without latency/error caliber.
- **Registered Exemption (登记型豁免)** — A Known Exemption carrying a written removal condition and a named registration point; the exemption is deleted when the condition fires — the revocation path is what separates it from a silent waiver. _Avoid_: permanent unowned exemptions, exemptions with no removal condition.
- **Trigger Line (触发线)** — The suspension mechanism for deferred work: an item parks until a machine-checkable condition fires, then re-enters adjudication; an unread observation cycle is no-data, not zero (NOT_OBSERVED != 0). _Avoid_: "later" without a named condition, treating never-observed as a zero reading.
- **Good-Event Ratio (好事件占比)** — The preferred SLI form: events meeting threshold / total valid events (e.g. "SSE added delta ≤10ms in ≥99% of events"), separating tail spikes from systemic degradation. _Avoid_: bare p99 as a gate, averaged latencies, absolute WAN thresholds.
- **Probe Verdict (探针裁决)** — The typed per-port/tick signal-plane outcome: ok | local_fail | remote_fail | skipped | environment_suspect, joining loopback health with the egress probe to classify WHERE a failure lives. _Avoid_: boolean health flags, majority-rule port counts, unclassified "fail".
- **Common-mode Suppressor (共模抑制器)** — The tick-level guard stamping an entire tick environment_suspect when ≥80% of probed bound ports fail loopback together — one local outage is one environmental event, never N platform failures; suspect ticks are time barriers in the rings. _Avoid_: per-platform quorum tricks, suppressing partial-failure ticks, user-tunable thresholds.
