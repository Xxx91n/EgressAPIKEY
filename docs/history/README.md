# docs/history/ — HISTORICAL ARCHIVE

> **Not current truth.** These are session artifacts and phase plans from completed work.
> For current architecture, see `docs/architecture/`. For decisions, see `docs/adr/`.

## Structure

| Subdir | Contents | What it is |
|---|---|---|
| `phases/` | GRILL_T*, T4/T7, PROJECT_PLAN, BACKLOG | Done phase plans and execution backlogs |
| `handoffs/` | HANDOFF_* | Session handoff documents (agent-to-agent) |
| `prompts/` | USER_PROMPT_ARCHIVE, T9_MASTER_GOAL_PROMPT | Prompt archives, not engineering docs |

## Why this exists

Per the governance principle: constraints stay, history moves.
Phase plans and handoffs are point-in-time artifacts; they record *what was done*, not *what to do now*.
Archiving them here keeps the active docs surface clean for current and future contributors.
