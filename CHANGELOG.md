## [Unreleased]

### Security

- (round8 T03, spec IMP-4 / A-007) headless control-surface hardening: the headless server now enforces a shared `--auth-token` on every `/api/v1/*` + `/metrics/*` request (256-bit token from the OS CSPRNG via `getrandom`; time+PID entropy explicitly rejected) and a `Host` / `Origin` allowlist on every request (DNS-rebinding mitigation, same shape as Caddy / Envoy / nginx); binding a non-loopback address without `--auth-token` now refuses to start instead of silently exposing the full admin plane; a valid token arriving via `?auth_token=` plants an `HttpOnly; SameSite=Strict` session cookie so the SPA authenticates without holding the token in JS; new `--allowed-host` flag for deployments reached through a name other than the bind address (TLS reverse proxy); threat model + residual-risk register added to `docs/how-to/HEADLESS_DEPLOYMENT.md`; primitives + 14 unit tests in `src-tauri/src/headless_security.rs`; no new IPC commands (manifest stays 78) and no new config keys.
